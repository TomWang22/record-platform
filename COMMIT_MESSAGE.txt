feat(infra,listings): Complete observability stack + listings enhancements

## Overview
Comprehensive observability stack implementation with all service meshes and APM tools, plus enhanced listings service with ratings, time preferences, and auction deadline tracking.

## Observability Stack - Complete Setup

### Core Components
- **Prometheus**: Metrics collection with 50Gi storage, 30-day retention
- **Grafana**: Visualization with 10Gi storage, custom dashboards
- **Jaeger**: Distributed tracing (all-in-one deployment)
- **OpenTelemetry Collector**: OTLP receiver/processor with multi-export capability

### Service Meshes
- **Linkerd**: Lightweight service mesh with mTLS, traffic management, Linkerd Viz dashboard
- **Istio**: Advanced service mesh with Kiali, Prometheus, Grafana, Jaeger addons
- **Installation**: Configurable via `SERVICE_MESH` environment variable (default: linkerd)

### APM Integration
- **New Relic**: Full integration via OpenTelemetry Collector
- **Configuration**: License key via environment variable or Kubernetes secret
- **Exports**: Traces, metrics, and logs automatically forwarded to New Relic

### Installation Script
- **Enhanced**: `infra/k8s/scripts/install-observability.sh`
  - Installs Prometheus + Grafana via Helm chart
  - Deploys Jaeger and OpenTelemetry Collector
  - Applies ServiceMonitors and PodMonitors
  - Installs Linkerd or Istio (configurable)
  - Configures New Relic integration (if license key provided)
  - Comprehensive verification and status reporting
  - Detailed port-forward commands and access URLs

### Installation Scripts
- `infra/k8s/scripts/install-linkerd.sh` - Linkerd service mesh installation
- `infra/k8s/scripts/install-istio.sh` - Istio service mesh installation

## Usage

### Install Observability Stack
```bash
# Install all components (default: Linkerd)
bash infra/k8s/scripts/install-observability.sh

# Install with Istio instead
SERVICE_MESH=istio bash infra/k8s/scripts/install-observability.sh

# Install Linkerd separately
bash infra/k8s/scripts/install-linkerd.sh

# Install Istio separately
bash infra/k8s/scripts/install-istio.sh

# Configure New Relic
export NEW_RELIC_LICENSE_KEY='your-key-here'
bash infra/k8s/scripts/install-observability.sh
```

### Access Observability Tools
```bash
# Grafana
kubectl -n monitoring port-forward svc/monitoring-grafana 3000:80
# Login: admin/Admin123!

# Prometheus
kubectl -n monitoring port-forward svc/monitoring-kube-prom-prometheus 9090:9090

# Jaeger
kubectl -n observability port-forward svc/jaeger 16686:16686

# OpenTelemetry Collector
kubectl -n observability port-forward svc/otel-collector 4317:4317

# Linkerd Viz
linkerd viz dashboard

# Istio Kiali
istioctl dashboard kiali
```

### Apply Database Migrations
```bash
# Ratings and time preferences
PGPASSWORD=postgres psql -h localhost -p 5435 -U postgres -d records -f infra/db/05-listings-ratings-timezone.sql
```
