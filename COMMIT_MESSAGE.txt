## CI

- **QUIC hostname invariant:** `scripts/check-no-ip-quic.sh` enforces no `curl --http3` to raw IP URLs (use hostname e.g. record.local with `--resolve`). `.gitignore`: added `!scripts/check-no-ip-quic.sh` so the script can be committed; CI runs `bash scripts/check-no-ip-quic.sh` and fails with a clear error if the script is missing.
- **Transport validation:** When `transport_validator.py` is run with no pcap it exits 2 with `{"error": "no pcap provided"}`. Step now uses `set +e` before capturing output/exit code so the job doesn’t fail before the check; if output contains "no pcap provided" we exit 0; otherwise we propagate the validator exit code. tshark is only installed when `vm.pcap` exists.
- **Build:** Removed separate `build-common` job and cache. Each matrix build job runs `pnpm install`, builds the common package, then builds the service. Reliable and self-contained; no cross-job cache dependency.
